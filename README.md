# 分享卡片转文字

QQ 里分享 B站视频、网页时，消息是 Json 卡片、没有纯文本——模型完全看不到内容。
本插件在消息处理最前端把卡片提取成「标题/内容/链接」纯文本追加进消息：

- B站分享 → 提取标题 + b23/B站链接 → 模型调用 bilibili_read（BiliRead 插件）看字幕回应
- 网页分享 → 提取标题 + 链接 → 模型调用 analyze_webpage（web_analyzer 插件）分析总结
- 私聊分享必定回应；群聊分享进入上下文，读空气/@ 时可聊

提取优先 B站/b23 短链。配合 BiliRead + web_analyzer 使用。
